说明：
市场洞察 Agent 下包含商品卖点分析、市场分析、消费者分析三个大场景；以下专项列举**商品卖点分析**各环节的评估验证点，供模型评分参考。

**适用范围**：二、竞品筛选 和 四、竞品卖点对比 仅在任务涉及竞品对比时生效（用户明确提出竞品品牌，或意图识别 1.4 判定需进行对比）。否则两节整体跳过，不计入评分。

**判定说明**：
- ✅ Pass：得满分
- ⚠️ Review：有部分分值或需人工核查（主观项、有中间分的客观项）
- ❌ Fail：得 0 分；一票否决触发时整节为 Fail

## 一、意图识别

| # | 验证点 | 评估标准 | 类型 | 满分 | 得分规则 | 判定 |
|---|--------|----------|------|------|----------|------|
| 1.1 | 信息提取准确性 | 从用户输入中正确提取「品牌」「商品名称」「目标市场」三要素，无遗漏、无错配 | 客观 | 3 | 全对得 3；任一错误得 0 | Pass = 3 / Fail = 0 |
| 1.2 | 缺失信息处理 | 三要素任一缺失时，**必须暂停任务**并向用户明确询问，不得猜测推进 | **一票否决** | — | 自行推断推进 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |
| 1.3 | 无效确认识别 | 用户回复模糊（如「嗯」「随便」「你看着办」）时，Agent 应追问而非视为有效确认 | 客观 | 3 | 追问得 3；直接推进得 0 | Pass = 3 / Fail = 0 |
| 1.4 | 竞品需求判断 | 正确判断用户是否需要进行竞品对比（明确提出 → 进入竞品流程；未提出 → 按情况 B 处理） | 客观 | 4 | 判断正确得 4；判断错误得 0 | Pass = 4 / Fail = 0 |

## 二、竞品筛选

## 总分计算

### 第一步：判断评估模式

| 条件 | 模式 | 参与计分的节 |
|------|------|--------------|
| 任务涉及竞品对比（用户明确提出竞品 或 1.4 判定需进行对比） | **Mode A** | 一、二、三、四、五 |
| 任务不涉及竞品对比 | **Mode B** | 一、三、五 |

### 第二步：加权求总分

**Mode A（含竞品对比）**

**总分** = 一×0.15 + 二×0.15 + 三×0.25 + 四×0.15 + 五×0.30

**Mode B（不含竞品对比）**

**总分** = 一×0.20 + 三×0.35 + 五×0.45

总分范围：**0 – 10 分**

### 第三步：最终判定

| 总分 | 最终判定 |
|------|----------|
| ≥ 8.0 | ✅ Pass |
| 6.0 – 7.9 | ⚠️ Review（需人工复核） |
| < 6.0 | ❌ Fail |

> 注：任意节触发一票否决，无论总分高低，最终判定直接为 ❌ Fail。
