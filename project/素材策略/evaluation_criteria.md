# 素材策略 Agent 评估标准

> 适用范围：素材策略 Agent ATM 测试用例的 Mode C 评分。
> 
> **判定说明**：
> - ✅ Pass：得满分
> - ⚠️ Review：有部分分值或需人工核查
> - ❌ Fail：得 0 分；一票否决触发时整节为 Fail

---

## 一、信息提取与确认（权重 × 0.20）

| # | 验证点 | 评估标准 | 类型 | 满分 | 得分规则 | 判定 |
|---|--------|----------|------|------|----------|------|
| 1.1 | 字段提取准确性 | 商品名称、行业类目、卖点列表、价格信息从输入中正确提取，无错配、无编造 | 客观 | 3 | 全字段正确得 3；任一字段错误或编造得 0 | Pass = 3 / Fail = 0 |
| 1.2 | 必填字段强制校验 | 商品名称 / 行业类目（≥3级）/ 核心卖点（≥1条）任一缺失时，「开始推演」必须不可点击 | **一票否决** | — | 缺必填仍可推演 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |
| 1.3 | Brief 优先级 | 用户文本中的受众/节点/促销 Brief 信息优先于 URL 抓取，冲突字段标注 `[✨ 取自投放要求]` | 客观 | 2 | 优先级正确且标注得 2；优先级正确但未标注得 1；优先级错误得 0 | Pass = 2 / Review = 1 / Fail = 0 |
| 1.4 | URL 失败兜底 | URL 解析失败时流程不中断，确认页相关字段留空，不报错退出 | 客观 | 2 | 流程继续得 2；报错退出得 0 | Pass = 2 / Fail = 0 |
| 1.5 | 商品图轻提示 | 商品主体占比 < 20% 时触发轻提示，但不阻断流程 | 客观 | 1 | 有提示且不阻断得 1；阻断流程或无提示得 0 | Pass = 1 / Fail = 0 |
| 1.6 | 字段不编造 | 商品信息稀少时（如仅商品名），缺失字段保持空值，不猜测填充 | **一票否决** | — | 出现编造字段 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |

节得分 = (1.1 + 1.3 + 1.4 + 1.5) / 8 × 10（满分 10；1.2 或 1.6 触发则强制为 0）

## 二、策略路径生成合规性（权重 × 0.25）

| # | 验证点 | 评估标准 | 类型 | 满分 | 得分规则 | 判定 |
|---|--------|----------|------|------|----------|------|
| 2.1 | 无价格时禁止价格路径 | price_info = null / 无折扣信息时，生成路径中不含任何价格/促销/限时相关描述 | **一票否决** | — | 路径中出现价格/促销内容 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |
| 2.2 | L3 心理钩子合规 | L3 只从 6 种（身份认同 / 损失厌恶 / 限时紧迫 / 反差对比 / 认知失调 / 情感共鸣）中选取，不超出 | **一票否决** | — | 出现 6 种以外的心理钩子 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |
| 2.3 | L2 具体化 | 每条路径 L2 包含具体人群 + 场合 + 痛点（爽点）三要素，不使用「年轻人」「消费者」等宽泛标签 | **一票否决** | — | L2 使用宽泛标签或缺少三要素之一 → 全节 = 0 | Pass = 未触发 / Fail = 触发（全节归零） |
| 2.4 | L1 只含客观物理属性 | L1 USP 描述为可量化的物理参数或客观功能，不含品牌故事、情感主张等主观描述 | 客观 | 3 | 全部 L1 符合得 3；部分不符得 1.5；全部不符得 0 | Pass = 3 / Review = 1.5 / Fail = 0 |
| 2.5 | 路径本质差异 | 同一商品生成的各路径 L2 人群/场景无重复，路径间有本质差异 | 主观 | 3 | 各路径明显不同得 3；部分相似得 1.5；高度雷同得 0 | Pass = 3 / Review = 1.5 / Fail = 0 |
| 2.6 | 信息不足时宁缺毋滥 | 商品信息极少时，路径数量减少（甚至为 0 + 提示），不强行生成低质路径 | 客观 | 2 | 路径数合理或给出提示得 2；强行生成相似路径得 0 | Pass = 2 / Fail = 0 |
| 2.7 | 质量门控执行 | L2 缺三要素的路径被过滤，不传入 Prompt 5；过滤有记录 | 客观 | 2 | 过滤生效得 2；漏过滤得 0 | Pass = 2 / Fail = 0 |

节得分 = 2.4 + 2.5 + 2.6 + 2.7（满分 10；2.1、2.2、2.3 任一触发则强制为 0）

## 总分计算

### 加权公式

**总分** = 一×0.20 + 二×0.25 + 三×0.25 + 四×0.15 + 五×0.15

总分范围：**0 – 10 分**

### 最终判定

| 总分 | 最终判定 |
|------|----------|
| ≥ 8.0 | ✅ Pass |
| 6.0 – 7.9 | ⚠️ Review（需人工复核） |
| < 6.0 | ❌ Fail |

> 注：任意节触发一票否决，无论总分高低，最终判定直接为 ❌ Fail。

## 一票否决汇总

| 否决点 | 所在节 | 触发条件 |
|--------|--------|---------|
| 必填字段缺失仍可推演 | 一 | 商品名/类目/卖点缺失时「开始推演」可点击 |
| 字段编造 | 一 | 信息稀少时凭空填写字段值 |
| 无价格生成价格路径 | 二 | price_info=null 时路径含价格/促销描述 |
| L3 超出 6 种以外 | 二 | 出现非规定心理钩子类型 |
| L2 使用宽泛标签 | 二 | 人群描述无具体人群+场合+痛点/爽点 |
| 无价格时文案含价格 | 三 | price_available=false 时文案出现价格/折扣 |
| invalid 输入触发生成 | 四 | NL 无关内容路由至生成下游 |
| HITL 1 被跳过 | 五 | 未经产品确认直接推演 |
| HITL 2 被跳过或空选推进 | 五 | 未经路径选择或空选直接生成卡片 |

## 主观项评分锚点

| 得分（占满分比） | 判定 | 描述 |
|-----------------|------|------|
| 满分 | ✅ Pass | 有具体依据，逻辑无懈可击 |
| 50%–99% | ⚠️ Review | 符合要求但有瑕疵，或部分达标 |
| 1%–49% | ⚠️ Review | 基本满足，明显不足 |
| 0 | ❌ Fail | 严重不达标或完全缺失 |
